Project capabilities

What the repository implements

A compact view of the project’s actual architecture and application flows.

Authentication

Firebase email/password sign-in and account registration with authenticated user state.

Shopping Cart

Per-user cart data with quantity, pricing, review and checkout flows.

Soil Testing

Date availability check, soil-testing route and booking form with optional previous report upload.

REST Backend

Flask-RESTful APIs for products and cart operations with SQLAlchemy models.

Admin Management

Admin routes support adding products and product update/delete operations.

Responsive UI

React application with React Router, Reactstrap/Bootstrap and Material UI dependencies.
