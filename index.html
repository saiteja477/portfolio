End-to-end workflow

Architecture based on the current rebuild rather than the older Selenium-only prototype.

1Resume & profileUpload/parse resume and persist user profile/session state.
2Dice searchFastAPI calls DicePortal; Playwright extracts real job cards.
3Match scoringQuick skill scoring with matched and missing skills; NLP matching layer supports deeper fit analysis.
4Prepare & reviewOpen the application flow, detect supported fields, then approve, skip or request review.
5Submit & trackTrack submitted, already-applied, review-required and failed automation states.
React / Vite→FastAPI API→SQLite profile & session state→DicePortal→Playwright→Applications
